# Стабильный ABI

Моды и загрузчик общаются через `fish-abi`: `#![no_std]`, ноль зависимостей, всё `#[repr(C)]`.
Изменение раскладки не компилируется (проверки `size_of`/`offset_of` для x86_64 и aarch64).

## Версионирование

`FISH_ABI_MAJOR`/`FISH_ABI_MINOR` (сейчас 0.1). Пока major равен 0, minor хоста и мода должны быть
**равны**. С 1.0 minor хоста должен быть не меньше minor мода, а major — совпадать.
Отклонённый мод сообщает: `<id> was built for Fish ABI X.Y; this Fish serves A.B`.

## Экспорт мода

Каждая библиотека мода экспортирует `extern "C" fn fish_mod_v1() -> *const FishModV1` — указатель на статические данные:

```text
FishModV1 { size, abi_major, abi_minor, entrypoints, entrypoint_count }
FishEntrypointV1 { key, name, kind (0 init | 1 object), init, object }
```

Загрузчик проверяет, что каждая запись `[entrypoints]` манифеста существует и имеет верный тип:
`pre_launch`, `main`, `client` и `server` — точки входа `init`, любой другой ключ — `object`.
`fish_api::export_mod!` генерирует всё это.

## Таблица хоста

`FishHostV1` передаётся каждой точке входа `init`. В ней `host` (непрозрачный, возвращается в каждый
вызов), `mod_token` (идентифицирует вызывающий мод) и указатели: `log`, `get_service`,
`event_define`, `event_lookup`, `event_register`, `event_phase_order`, `event_invoke`,
`event_invoke_index`.

## Сервисы

Каждый модуль Fish API — сервис: id `fish:<module>`, таблица `#[repr(C)]`, начинающаяся с
`{ size, version }`. Функции только добавляются; перед вызовом функции, добавленной после версии 1,
проверяйте `size`. Первый сервис — `fish:loader` (моды, каталоги, object share, объектные точки входа).

## Правила

- **Коды статуса**: `FishStatus` (`OK=0`, `INVALID_ARGUMENT=-1`, `NOT_FOUND=-2`, `UNSUPPORTED=-3`,
  `PANICKED=-4`, `STALE_HANDLE=-5`, `WRONG_THREAD=-6`, `ALREADY_EXISTS=-7`, `TYPE_MISMATCH=-8`,
  `VERSION_MISMATCH=-9`, `INTERNAL=-100`). Результаты действий идут как `u8` и проверяются, а не приводятся.
- **Строки** — `FishStr { ptr, len }` (UTF-8, заимствованы на время вызова). Строки хоста (информация
  о модах, каталоги) живут столько же, сколько загрузчик.
- **Память** освобождает только тот модуль, который её выделил.
- **Паники** не пересекают границу. Каждая `extern "C"` функция с обеих сторон их перехватывает; паника
  в моде возвращает `PANICKED`, хост помечает мод *failed* и пропускает его слушателей (или завершает
  процесс при `FISH_LOADER_STRICT=1`). Собирайте моды с `panic = "unwind"`.
- **Дескрипторы** (`FishHandle { index, generation }`) действительны только внутри колбэка, который их получил.
- **Нагрузки событий** — структуры `#[repr(C)]`, начинающиеся с `size: u32`; поля только добавляются.
- **Потоки**: слушатели могут выполняться в потоке рендера и серверном потоке, поэтому слушатели —
  `Fn + Send + Sync + 'static`.
- **Изоляция**: загрузчик распаковывает каждую библиотеку в `<game dir>/.fish/cache/<id>-<version>-<hash>/`,
  поэтому у каждого экземпляра загрузчика свой экземпляр модуля (и свои статики мода).
