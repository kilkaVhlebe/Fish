# Реестры

`fish_api::registry` ведёт реестры Fish: идентификаторы (`namespace:path`) с raw id.

```rust
let raw = fish_api::registry::register("fish:blocks", "mymod:ruby_block")?;
```

- Регистрируйте, пока выполняется `pre_launch` или `main`. Когда точки входа всех модов выполнены, реестры
  **заморожены**: поздний вызов возвращает `registries are frozen`, загрузчик пишет предупреждение.
- Повторная регистрация того же id возвращает тот же raw id.
- Raw id идут в порядке регистрации (порядок загрузки модов, затем порядок вызовов). При входе на сервер они
  перенумеровываются по серверным, поэтому не храните raw id; получайте через `raw_id`.
- Записи модов с `environment = "*"` синхронизируются с сервером (см. [Сеть](networking.md)); записи модов только для
  клиента или сервера остаются локальными.

## Состояние

Это ядро реестров. Предметы, группы, звуки и частицы (остальное в P8; у игровых правил и блоков свои страницы: [игровые правила](game_rule.md) и [блоки](block.md)) не реализованы:
им нужны хуки оверлея контента в Horizon.
