# Строки F3, отчёты о падении и остановленные моды

## F3

`fish_api::event::debug::F3_LINES` приходит в каждом кадре, где рисуется экран F3; добавляйте строки через
`ctx.add_line(text)` (не больше 32 строк по 200 символов; лишние отбрасываются). Свою первую строку Fish добавляет
всегда: `[Fish] 0.1.0 - N mod(s)`.

```rust
use fish_api::event::debug::F3_LINES;

F3_LINES.register(|c| c.add_line("мой мод: 3 машины работают"))?;
```

## Когда мод падает

Мод падает, если точка входа или слушатель паникует либо возвращает ошибку. Тогда Fish:

- пишет в журнал `Fish mod <name> stopped: <причина>` и до конца сессии не вызывает его слушателей и команд,
- показывает ту же строку в чате игрока на следующем тике клиента,
- показывает мод в **Options > Mods** как `Name 1.0 [Fish] (stopped)` с причиной в описании,
- добавляет `Fish`, `Fish mods` и `Fish failed mods` в **System Details** отчётов о падении (`crash-reports/`),
  чтобы отчёт всегда говорил, какой Fish и какие моды работали.

Моды, зависящие от упавшего, падают с сообщением `dependency <id> failed to load`.
