# События жизненного цикла

`fish_api::event::lifecycle`. У каждого события здесь [`GameContext`](events.md#game-events), кроме тиков:
у них `TickContext`.

| Событие | Когда | Поля |
| --- | --- | --- |
| `client::START_TICK`, `END_TICK` | каждый тик игры окна (в мире) | `TickContext` |
| `client::STARTED` | первый кадр окна (включая заставку) | role |
| `client::STOPPING` | окно закрывается, мир ещё не сохранён | role |
| `client::STOPPED` | окно закрыто и сохранено; **нет вида игры** (`client()` возвращает ошибку) | role |
| `server::START_TICK`, `END_TICK` | каждый тик встроенного или выделенного сервера | `TickContext` |
| `server::STARTING` | сервер начинает грузить мир | `subject` = имя мира |
| `server::STARTED` | первый тик сервера | role |
| `server::STOPPING` | сервер начинает останавливаться, игроки ещё не сохранены | role |
| `server::STOPPED` | сервер сохранён и закрыт | role |
| `world::LOAD` | уровень (измерение) загружен | `dimension` |
| `world::UNLOAD` | уровень будет выгружен; при остановке сервера приходят все | `dimension` |
| `chunk::LOAD`, `UNLOAD` | чанк попадает в загруженные или покидает их; **нет вида игры** | `pos()` = `x`, `z` чанка |
| `reload::START` | выполняется `/reload` | role |
| `reload::END` | первый тик сервера после `START` (данные готовы) | role |

```rust
use fish_api::event::lifecycle::{server, world};

server::STARTED.register(|c| log::info!("сервер запущен ({:?})", c.role()))?;
world::LOAD.register(|c| log::info!("уровень {} загружен", c.dimension()))?;
```

## Замечания

- Одиночная игра запускает *две* игры: окно (`Role::Window`) и встроенный сервер (`Role::IntegratedServer`).
  `client::*` приходят в окне, `server::*` — на сервере. У выделенного сервера только `server::*`.
- `client::STARTED`, `server::STARTED` и первый `world::LOAD` выводятся загрузчиком из первого кадра и первого
  тика сервера; в процессе они приходят ровно один раз.
- `world::LOAD` первого уровня приходит на первом тике сервера, до `server::STARTED`; остальные уровни — когда игра
  их открывает. `world::UNLOAD` приходит для каждого загруженного уровня при остановке сервера (уровни, которые игра
  закрывает по простою, не сообщаются).
- `chunk::*` приходят из горячего пути: если событие никто не слушает, Fish его пропускает целиком. Держите
  слушатели дешёвыми. Измерение там неизвестно; используйте только `pos()`.
- `reload::END` наблюдается на следующем тике сервера, а не синхронно.
