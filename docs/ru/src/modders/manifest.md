# Манифест мода (`fish.mod.toml`)

У каждого мода в корне архива `.fish` (или каталога) лежит `fish.mod.toml`. Схема 1.
Неизвестные ключи — ошибка. Манифест с большим `schema` отклоняется сообщением
`this mod was made for a newer Fish (schema N); update Fish`.

```toml
schema = 1                               # обязателен
id = "example_mod"                       # обязателен; ^[a-z][a-z0-9_]{1,63}$
version = "1.0.0"                        # обязателен; SemVer 2.0
name = "Example Mod"                     # по умолчанию — id
description = ""
authors = ["…"]
contributors = []
license = "MIT"                          # строка SPDX, не проверяется
icon = "icon.png"                        # путь в архиве
environment = "*"                        # "*" | "client" | "server"
provides = ["alias_id"]                  # алиасы; правила как у `id`
nested = ["nested/lib.fish"]             # архивы внутри этого

[contact]                                # произвольные строки
homepage = "https://example.com"

[library]                                # нужна, если объявлены entrypoints
name = "example_mod"                     # файл = DLL_PREFIX + name + DLL_SUFFIX

[entrypoints]                            # ключ → имена, экспортированные export_mod!
pre_launch = []
main = ["init"]
client = ["init_client"]
server = []
"fish:modmenu" = ["menu_api"]            # любой другой ключ — пользовательская точка входа

[depends]                                # id = "req" или ["req", "req"] (массив = ИЛИ)
fish = ">=0.1.0"
[recommends]                             # отсутствует/не подходит → предупреждение
[suggests]                               # информационно
[conflicts]                              # есть и подходит → предупреждение
[breaks]                                 # есть и подходит → ошибка

[custom]                                 # произвольная таблица, для чтения модами
```

## Идентификаторы

`^[a-z][a-z0-9_]{1,63}$`. Идентификаторы `fish`, `fish_api`, `horizon` и `minecraft` зарезервированы:
их нельзя использовать как `id` или в `provides`, но можно указывать в таблицах зависимостей.

## Требования к версиям

Синтаксис — `semver` из Rust (`>=1.2`, `^1`, `<2, >=1.5`, `*`). Массив означает «любое из».
Пре-релизы подчиняются правилам semver, кроме встроенных кандидатов загрузчика: у них пре-релиз
считается своим релизом (`0.2.0-nightly.1` удовлетворяет `>=0.2.0`).

## Встроенные кандидаты

| id | версия |
| --- | --- |
| `fish`, `fish_api` | версия Fish |
| `minecraft` | `26.3.0` |
| `horizon` | `<линейка>.0-nightly.<ГГГГММДД>+<короткий коммит>` |

## Разрешение зависимостей

- Моды, чьё `environment` не подходит текущей стороне, игнорируются.
- При дубликатах id побеждает старшая версия (при равенстве — dev-мод); оба пути называются в предупреждении.
- Каждая `depends` должна выполняться, ни одна `breaks` не должна подходить, id и алиас принадлежат одному моду.
- Вложенные архивы загружаются, только если их можно удовлетворить; выбирается старшая совместимая версия.
- Порядок загрузки: сначала зависимости, затем по id. Цикл зависимостей упорядочивается по id с предупреждением.
- Поиск ограничен (100 000 шагов).

Ошибки называют мод, требование и то, что установлено, например:
`mod "a_mod" 1.0.0 needs "b_mod" >=2, but only 1.4.0 is installed (fish-mods/b_mod.fish)`.
