# Использование модов

Кладите файлы `.fish` в папку `fish-mods/` вашего экземпляра Fish (установщик её создаёт; игровая папка экземпляра
показана в лаунчере). Запускайте игру кнопкой **Играть** на экземпляре Fish.

- Мод, который сейчас не нужен: переименуйте в `name.fish.disabled`. Файлы, начинающиеся с точки, тоже игнорируются.
- Мод может быть обычной папкой с `fish.mod.toml`.
- Моды, которым нужны другие моды (или более новый Fish), сообщают об этом в журнале игры и пропускаются; остальные загружаются.
- **Options > Mods** показывает каждый загруженный мод Fish как `Name 1.0 [Fish]`.
- Мод, который упал, отключается до конца сессии; игра продолжает работать. Журналы — в `logs/latest.log` экземпляра
  (строки начинаются с `[fish]` или `[fish/<id мода>]`).

Моды — нативный код с теми же правами, что у игры. Ставьте только те, которым доверяете.
