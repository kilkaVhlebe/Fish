# Установка Fish

Fish подключается к официальному лаунчеру Horizon. Нужен лаунчер с установленным Horizon Nightly.

## Через окно

1. Запустите `fish-installer` (без аргументов откроется окно).
2. Проверьте путь к лаунчеру (он находится сам, если лаунчер установлен или запущен; иначе — **Обзор…**).
3. Оставьте включённым **Выбрать Fish в лаунчере**, чтобы «Играть» запускало экземпляр Fish, и нажмите **Установить**.
4. Когда появится *Готово*, нажмите **Открыть лаунчер Horizon**.

Окно следует языку системы (английский или русский).

## Из командной строки

```text
fish-installer install [--launcher PATH] [--instance NAME] [--edition ZIP] [--select] [--force] [--allow-unsigned] [--yes]
fish-installer repair | update | uninstall | status
```

- `install` берёт из индекса релизов новейшее издание для вашей платформы, проверяет подпись и SHA-256, распаковывает
  его в домашний каталог Fish, ставит Horizon в лаунчере, если нужной версии нет, создаёт экземпляр (по умолчанию
  **Fish**), закрепляет за ним эту версию Horizon и задаёт *обёртку запуска* — `fish-launch`.
- `--edition ZIP` ставит локальный архив издания (сборка из исходников: см. «Сборка изданий»).
- `repair` переустанавливает записанное издание и чинит экземпляр; `update` переходит на новейшее издание.
- `uninstall` очищает обёртку и удаляет издания и бинарники Fish. **Экземпляр, его миры и папка `fish-mods`
  сохраняются.**
- `--force` заменяет обёртку, которую вы сами задали этому экземпляру; без него установщик откажется.
- `--allow-unsigned` (или `FISH_LOADER_ALLOW_UNSIGNED=1`) принимает неподписанный индекс. Только для разработки.

## Где что лежит

| Что | Где |
| --- | --- |
| Домашний каталог Fish | `%APPDATA%\fish-loader` (Windows), `~/.local/share/fish-loader` (Linux), `~/Library/Application Support/fish-loader` (macOS); переопределяется `FISH_LOADER_HOME` |
| Издания, обёртка, установщик | `<home>/editions`, `<home>/bin`, `<home>/installer.json` |
| Ваши моды | игровая папка экземпляра, `fish-mods/` |

Fish никогда не пишет в файлы самого лаунчера. Всё делается командами `horizon-launcher`.

## Ручная проверка

1. Запустите установщик. В лаунчере появится экземпляр **Fish**; в его панели *Launch…* сказано, что он запускается
   через `…fish-launch.exe`.
2. Нажмите **Играть**. В игре **Options > Mods** показывает моды как `Name 1.0 [Fish]`.
3. Положите `hello.fish` в `fish-mods/`: в левом верхнем углу HUD появится *Hello from Fish*.
4. `fish-installer uninstall`, затем «Играть»: запустится обычный Horizon.
